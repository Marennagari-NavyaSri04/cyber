Cyber-Physical System Security

Manufacturing Industry 4.0 Protection Using LSTM-CNN Parallel Orchestration

System Overview

This framework implements an intelligent cyber-physical system (CPS) security solution for smart manufacturing environments in Industry 4.0. A parallel LSTM-CNN orchestration model is employed to detect anomalous and malicious behaviors in industrial sensor, controller, and network communication data.

Security Detection Targets:
  • Denial-of-Service Intensity: Low, Medium, High, Critical
  • Spoofing / Impersonation Attacks: None, Low, Medium, High
  • False Data Injection: Normal, Suspicious, Malicious
Learning Architecture:
  • Parallel LSTM Temporal Modeling
  • CNN-Based Spatial Feature Learning
  • Feature-Level Orchestration Layer
  • Multi-Class CPS Attack Classification
